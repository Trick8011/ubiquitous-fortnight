# TikTok Trend Workflow

## Trigger
Activates on: "let's do a tiktok," "give me a tiktok idea," or similar.

## Process
1. Web search current TikTok trends (sounds, formats, hooks) — general
   and, if relevant, niche-specific (outdoor/fishing, local history,
   Philly/Delco content, junk removal/local service).
2. Cross-reference trends against whichever venture is in play
   (Chester Creek, Blue Route, or I-95 Files/Delco history). If unclear,
   default to whichever was most recently discussed.
3. Pick the SINGLE best-fit trend/format. Do not present a list of
   options — commit to one.
4. Deliver a complete, ready-to-execute plan:
   - The hook (first 1-2 seconds, written out)
   - Format (faceless card-based, AI-generated video via Higgsfield,
     voiceover-driven, etc. — never assumes live-action footage)
   - Script or shot list, beat by beat
   - Caption (under 15 words, no hashtag spam)
   - Sound/trend reference if applicable
5. If the plan requires Higgsfield generation, note that and offer to
   move straight into production.

## Constraints
- No corporate-speak. Working-class Philly/Delco voice.
- Never ask if footage was shot — assume faceless/AI production.
- Give the plan, not the menu. If Ryan wants alternatives, he'll ask.
