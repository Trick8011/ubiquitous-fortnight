# River Towns — The Pagans in Delaware County

A Ken Burns–style documentary package about the Pagan's Motorcycle Club's historical and
present-day presence in Delaware County, Pennsylvania.

## Contents

| File | What it is |
|------|------------|
| `SCRIPT.md` | Full shooting script — three acts, shot-by-shot visuals, narration, music cues, interview placeholders |
| `VOICEOVER.md` | Condensed ~4-minute narration used for the finished voiceover cut |
| `IMAGE_GUIDE.md` | The generated cards + archival photo sourcing list with Ken Burns motion specs |
| `SOURCES.md` | Claim-by-claim source key and legal/ethics checklist |
| `DESIGN_PHILOSOPHY.md` | "Rust Archive" — the visual philosophy behind the cards |
| `images/` | Six finished 1920×1080 title/chapter/map/timeline cards |

## Editorial note

This is journalism about a real organization and real people. Allegations are attributed,
acquittals stated, and no private addresses identified. See `SOURCES.md` before making
any factual edit.
